## Setup

### 1. Clone the repo

```bash
git clone https://github.com/YOUR-USERNAME/tlevel-quiz.git
cd tlevel-quiz
```

### 2. Open in a browser

This is a **static site** — no build step, no server needed.

Just open `index.html` in your browser, or use a simple local server:

```bash
# Python (built-in)
python -m http.server 8080

# Or Node
npx serve .
```

Then visit `http://localhost:8080`.

> ⚠️ The quiz uses ES Modules (`type="module"`), so you **must** open it via a server (localhost), not by double-clicking the file directly. Most browsers block module imports from `file://` URLs.

### 3. Get an Anthropic API key

1. Go to [console.anthropic.com](https://console.anthropic.com)
2. Create an account and generate an API key
3. Click **⚙ API Key** in the top-right of the site
4. Paste your key — it starts with `sk-ant-`

Your key is saved to your **browser's localStorage only** — it is never in the source code, never uploaded to GitHub, and never sent anywhere except Anthropic's API directly.

---

## Deploying to GitHub Pages

1. Push the repo to GitHub
2. Go to **Settings → Pages**
3. Set source to `main` branch, `/ (root)` folder
4. Your site will be live at `https://YOUR-USERNAME.github.io/tlevel-quiz`

Each visitor enters their own API key — it stays in their browser.

## API Key Security

**Your API key is NEVER in this codebase.**

- `config.js` reads/writes from `localStorage` only
- There is no backend — the browser calls Anthropic's API directly
- Each user of the site provides their own key
- If you fork this repo, there is nothing sensitive to accidentally commit
